            Architecture & Approach

            Data sources → detection logic → storage, and exactly where official assets are excluded.

            How detection works

            1. Official assets removed first. Handles, package/bundle IDs, publisher names and domains from the brand profile are matched before any scoring, so official accounts and apps are never flagged.
            2. Look-alike names. Text is normalised (case, accents, separators), mapped through a homoglyph table (0→o, 1→l/i, Cyrillic а/е/о…), then compared by edit distance with transposition (character swaps), separator changes and added words. Support/trust words (support, official, wallet, refund…) score high; community words (fan, news, unofficial) score low.
            3. Avoiding over-flagging. A candidate needs a brand-related signal (name, logo, domain, description or package) before anything else counts. Short brand names (<5 chars) match only exactly; 5-letter names only on swaps. Verified badges reduce score. Anything marked “false positive” goes on an allow-list.
            4. Logo. A 64-bit difference hash of the official logo is compared with candidate images (Hamming distance).
            5. Links & text. Look-alike or foreign domains, shorteners, punycode, risky TLDs; copied description wording; scam phrasing (OTP requests, fees, giveaways).
            6. Apps. Publisher vs. official publisher (including look-alike publisher names), brand-like package IDs owned by someone else, risky permissions, new / low-install apps.
            7. Explainable score. Every finding lists each signal with its points, so a reviewer can verify it.

            2-minute demo script

            1. Brand Profile → Load demo brand (shows validation, logo fingerprint, official assets).
            2. Social → Run social scan: impostors flagged, official accounts excluded, fan page not flagged.
            3. Apps → Run app store scan: wallet clone, typo-squat, look-alike publisher.
            4. Settings → simulate a Facebook outage, rescan: partial-results banner, retry.
            5. Open a finding: evidence breakdown + takedown draft. Mark one false positive.
            6. Social → Manual check with n0vapay_support to show live look-alike detection.
